# TopBlog

**TopBlog** is a modern blogging platform built with **Laravel**, styled using **Blade** templates and **Tailwind CSS**. It offers all the core features needed to manage and share content through a clean interface.

---

## 🚀 Features

- **User Authentication**
  - Secure registration and login
  - Password reset support

- **Blog Management**
  - Create, edit, and delete blog posts
  - Upload images to enhance content
  - Use a rich text editor for formatting

- **Categories & Tags**
  - Assign categories and multiple tags to posts
  - Filter and search by category or tag

- **Comments**
  - Readers can comment on posts
  - Authenticated user commenting system

---

## 🛠️ Tech Stack

- **Backend**: Laravel
- **Frontend**: Blade templating engine
- **Styling**: Tailwind CSS
- **Database**: MySQL (or any Laravel-supported DB)
- **Authentication**: Laravel Breeze
- **Rich Text Editor**: CKEditor
- **Image Upload**: Laravel File Storage
